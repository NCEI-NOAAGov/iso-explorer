# MI_Plan

_Usage: 1 = Mandatory, 0...1 = Optional, 0...* = Optional, can occur more than once_

| #   | Element                                                | Usage | Definition and Recommended Practice                                                                                                                                                                         |
|-----|--------------------------------------------------------|-------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1   | [instrument](/iso-explorer/MI_Instrument )             | 0...1 | Identification of the instrument or device used to make the observations or collect the data. Provide identifier of instrument, instrument type, general description and citations to supporting documents. |
| 2   | [operation](/iso-explorer/MI_Operation)                | 0...* |                                                                                                                                                                                                             |
| 3   | [platform](/iso-explorer/MI_Platform )                 | 1     | The platform hosting the instrument used to collect the observations. Provide identifier of platform, general description and citations to supporting documents.                                            |
| 4   | [acquisitionPlan](/iso-explorer/MI_Plan)               | 0...* |                                                                                                                                                                                                             |
| 5   | [objective](/iso-explorer/MI_Objective)                | 0...* |                                                                                                                                                                                                             |
